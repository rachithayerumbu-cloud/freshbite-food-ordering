# 🍕 FreshBite - Online Food Ordering Website
# 📖 About the Project

FreshBite is a responsive online food ordering website developed using **HTML, CSS, and JavaScript**. It provides users with an attractive interface to explore restaurants, browse food items, search meals, apply discounts, manage their cart, and place food orders.

The project focuses on creating a modern user experience with responsive design, interactive UI components, smooth navigation, and dynamic cart functionality.
