🍕 FreshBite - Online Food Ordering Website
FreshBite is a responsive online food ordering website that allows users to explore restaurants, browse food items, add items to cart, apply discounts, and place orders easily.

🚀 Features
🏠 Home page with attractive hero section
🍽️ Browse restaurants and food menu
🔍 Filter restaurants by cuisine and rating
🥗 Filter food items by category and diet
❤️ Account and wishlist
🛒 Add items to cart
➕ Increase/decrease cart quantity
💰 25% discount calculation on orders
👤 User login and account section
📦 Order history management
🧾 Checkout with delivery details
📱 Responsive design for mobile devices

🛠️ Technologies Used
HTML5
CSS3
JavaScript
